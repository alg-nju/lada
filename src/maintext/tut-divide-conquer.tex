\subsection{最近点对问题} \label{subsec:closest-pair}

我们可以保守地估计，当前检查的点$q_i$上下所有跟它距离可能更近的点，
也就是当前检查的点$q_i$在一个$4\times 4$的网格中，最多需要比较它周边15个点 \cite[\S 5.4]{Kleinberg06}。

大家对于这一更保守的估计反而有点疑惑，就是它为什么考虑了很多显然可以约减的情况。
针对这一情况，我们改用下面更细致一点的估计。
$q_i$只需要考虑它下面的点，连$q_i$自己，一共8个格子，
所以$q_i$至多需要考虑7个点。

{\itshape
    1960年，科尔莫戈罗夫在莫斯科大学组织了一个关于控制论中数学问题的研讨会，
        在会上他提出了$\Omega(n^2)$猜想以及计算复杂性的其他一些问题。
    不到一周，当时还是23岁学生的卡拉楚巴便找到了一种算法，
        仅用$O(n^{\log _{2}3})$次初等运算即可完成两个 n 位数相乘，从而推翻了该猜想。
    
    科尔莫戈罗夫对这一发现感到非常兴奋。
    他在研讨会的下一次会议上通报了这一成果，随后研讨会便宣告结束。
    科尔莫戈罗夫在世界各地的会议上就卡拉楚巴的成果作了一系列报告（例如见《1962年国际数学家大会论文集》第351–356页，
        以及《1962年斯德哥尔摩国际数学家大会上的6场演讲》），
        并于1962年在苏联科学院院报上发表了这一方法。
    该文由科尔莫戈罗夫撰写，其中包含关于乘法的两项成果——卡拉楚巴的算法和尤里·奥夫曼的另一项独立成果，
        文章署名"A. Karatsuba and Yu. Ofman"。
    而卡拉楚巴直到收到出版方寄来的抽印本时，才知道有这篇文章。
}
