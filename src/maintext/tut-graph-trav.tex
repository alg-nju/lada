\section*{授课提纲}

\nid 基本概念，几个教学型问题：
%--
\begin{itemize}
    \item 割点算法：$back$的初始化问题；与\ul{桥算法}的异同
    \item SCC算法：DFS是否可替换？
    \item BFS是否有白色路径定理
    \item DFS的基于栈的非递归实现；拓扑排序的另一种实现方法
    \item 小孩排队问题；选课问题
\end{itemize}


\nid 连通性相关典型问题：
%--
\begin{itemize}
    \item $s\textendash t$问题；$impact$问题
    \item \textit{semi-connected}问题
\end{itemize}

\nid 无向图的定向问题：
%--
\begin{itemize}
    \item \ul{入度$\geq 1$}定向；SCC定向
\end{itemize}


\nid 围绕遍历来解决部分图优化问题：
%--
\begin{itemize}
    \item BFS最短路径条数问题
    \item $remoteness(v)$问题
    \item 边过滤问题
    \item 限定边权的MST问题
    \item DAG图上的SSSP
\end{itemize}
